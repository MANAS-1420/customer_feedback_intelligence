# 🚀 Customer Feedback Intelligence System

An advanced AI/NLP project that analyzes customer reviews and extracts actionable insights.

---

## 🔥 Features

✅ Multilingual Support (English + Hindi + Hinglish)  
✅ Aspect-Based Analysis  
✅ Sentiment Detection (0,1,2)  
✅ Emotion Detection  
✅ Customer Intent Classification  
✅ Industry-Level Priority Scoring  
✅ Regex-based Smart Detection  
✅ Explainable AI (Keyword Highlighting)  
✅ Streamlit Dashboard  

---

## 🧠 Core Logic

This project uses a **Hybrid Approach**:

- Rule-based NLP (keywords)
- Regex pattern detection
- Weighted scoring system

👉 Instead of simple keyword matching, it combines multiple signals:

- Urgency detection
- Strong negative phrases
- Critical keywords (fraud, refund, etc.)

---

## ⚙️ How It Works

1. Upload CSV file
2. System processes reviews
3. Outputs:
   - Aspect
   - Sentiment
   - Emotion
   - Intent
   - Priority
